# 複数の AI と共有するナレッジベース

個人のナレッジベースを、開発を手伝う複数の AI と共有する仕組みの事例紹介です。説明は [knowledge-base-case-study.pdf](knowledge-base-case-study.pdf)（8 ページ）にまとめています。

## 扱う課題

AI ツールどうしは文脈を共有しないため、複数のリポジトリの AI に同じノートを読ませたくなります。一方で、ノートを一か所に集めると、どれが確かか分からなくなる、渡してはいけないものが渡る、増えるほど使いにくくなる、という三つが起きやすくなります。資料では、この三つに信頼・境界・持続の原則を立て、ノートのメタデータ、検索の窓口、定期的な点検でどう備えたかを説明します。

## 含まないもの

- 例はすべて架空です。実在の人物、組織、リポジトリ、ノートは使っていません。
- ナレッジベースの内容、コード、設定、実データ、実測値は含みません。
- このリポジトリには、この README と PDF だけを置いています。
